## Overview (EN)

Yule Mouse is an Obsidian plugin that provides three main features:

### Tab Pinning

Double-click the header of a tab to pin or unpin it. Pinned tabs stay visible in the main editor area and in pop-up windows.

### View Mode Toggle

Click the side margin of a note to toggle between "Source" (raw markdown) and "Preview" (live rendered view). The toggle is also available via double-click.

### Drag & Drop Text Between Tabs

Drag selected text from one tab to another to move it (insert at cursor position + remove from source). Hold Ctrl while dragging to copy instead of move.

## Обзор (RU)

Три функции:

### Закрепление вкладок кликом

Двойной клик по заголовку вкладки закрепляет и открепляет её.

### Переключение режимов

Щелчок по полям заметки переключает между режимами «Исходный код» и «Живой просмотр».

### Перетаскивание текста между вкладками

Перетащите выделенный текст из одной вкладки в другую, чтобы переместить его (вставка под курсором + удаление из источника). При зажатой **Ctrl** — копируется вместо перемещения.

---

## Installation

1. Copy files to your Obsidian plugins folder.
2. Enable the plugin in Obsidian settings → Community plugins → Browse.
